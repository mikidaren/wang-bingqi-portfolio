### 部署踩坑：资源上传通道抖动（重要）

`wrangler deploy` 在 `POST /accounts/{id}/workers/scripts/<name>/assets-upload-session` 阶段报 `fetch failed` 中断，本次**连续失败 4 次、第 5 次才成功**。

- **根因**：国内到 Cloudflare 上传通道的**间歇性抖动**，非配置问题。同期用 Node `fetch` 直测同一端点是 2 秒 HTTP 200，wrangler 侧却 22 秒超时断开。

- **重要性质**：wrangler 的资源上传**按内容哈希去重**。首次已传 35/53，后续重跑输出 `Uploaded 18 of 18 assets (35 already uploaded)` —— **重跑只传缺失部分，不会白费**。
- **对策**：不要改配置，**直接重跑 `npm run deploy`**（建议循环重试）。可设 `WRANGLER_SEND_METRICS=false` 减少无关遥测请求（它自己也在报 fetch failed，干扰判断）。

## 15:44–16:00 — 修 Git 凭据助手弹窗（用户报障）

**现象**：Windows 反复弹出小窗 —— 标题 `CredentialHel...`，内容「Select a credential helper」，选项 `<no helper>` / `manager` / `wincred`。

**排查**：`git config --list --show-origin | grep credential` 一次定位：

```
系统级  credential.helper=helper-selector      ← 元凶（PortableGit/etc/gitconfig）
全局级  credential.helper=!...git-credential-manager.exe
全局级  credential.helperselector.selected=manager
仓库级  credential.helper=store                ← 我 15:40 加的
```

`helper-selector` 是 GCM 的"选择器"模式：每次取凭据时检查 helper 列表，**列表里不止它一个就弹框问用哪个**。git 的 helper 列表跨层级累加（system → global → local），我在仓库级加 `store` 后变成 `[helper-selector, GCM, store]` → 立即开始弹窗。**弹窗是我造成的**，与用户无关。

**修法**（依据 git 官方 `gitcredentials(7)`：`credential.helper` 为空字符串会**清空此前累积的 helper 列表**——这是覆盖低优先级 helper 的唯一手段，上游 commit 见 2016 年 Jeff King 的补丁）：

```bash
cp ~/.gitconfig ~/.gitconfig.bak-20260915
git config --global --unset-all credential.helper
git config --global --add credential.helper ""      # 重置：干掉系统级 helper-selector
git config --global --add credential.helper store   # 只留 store
git config --global --unset-all credential.helperselector.selected
# 再删掉两个仓库的仓库级 credential.helper
```

**铁证**：

```
$ printf "protocol=https\nhost=github.com\n\n" | GIT_TRACE=1 git credential fill | grep run_command
run_command: 'git credential-store get'          ← 只有 store
```
`git-credential-manager` / `helper-selector` 调用次数 = **0**。实推 `git push origin main` 输出 `Everything up-to-date`，无弹窗。

**注意事项**：空值必须写在前面且用 `--add`（否则被覆盖，重置失效）；**仓库级不要再写 `credential.helper`**，重复条目会重新唤醒弹窗。

**取舍**：`store` = 明文存 `~/.git-credentials`，换来电与弹窗彻底消失。若要加密存储可改为只留 GCM，但首次认证会弹 GCM 的 GUI，非交互场景不可用。
